# 本地已验证文件

这两个文件用于按手册直接操作，无需自行编译。

- `Pico-v2.uf2`：本地已用的 Pico PIO 开漏 v2 固件，仅将一处错误信息中的构建机路径替换为通用路径；程序指令不变。脱敏副本未重新刷入验收。
- `相机只读引导.bin`：本地已用的 RAM Fastboot 程序，逐字节原样复制。只读，不是相机官方固件或私人备份。
- 大小、SHA-256与对应源码见[文件校验](文件校验.json)。

Pico 自有适配源码见[源码目录](../源码/硬件/Pico注入/pico_boot/)，上游归属沿用[NOTICE](../NOTICE)。编译使用 [Arduino-Pico 6.3.0](https://github.com/earlephilhower/arduino-pico/tree/6.3.0)，其源码及依赖版本由该标签提供；随附 Arduino-Pico、Pico SDK、TinyUSB 的[许可文本](许可/)。相机 RAM 程序的固定上游输入与适配脚本仍可用于自行构建。
