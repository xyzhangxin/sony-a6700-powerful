# A6700 2.00 照片 PPLUT 研究交接

我们想让 A6700 的**照片挡沿用机身原生 Picture Profile 菜单和自定义 LUT 管理**。用户导入 `.cube`、在 PPLUT1–4 中绑定 LUT 后，可以直接在机身选择，先用全尺寸相机直出 JPEG 验证 LUT 随照片写入，再验证取景。官方把 PPLUT1–4 限在视频挡，因此实机先借照片挡已有的 **PP1** 验证底层链路，确认效果后再研究往照片 PP 菜单接入 PPLUT 项。 [Sony Picture Profile](https://helpguide.sony.net/ilc/2320/v1/en/contents/0412D_picture_profile.html) · [Sony Manage User LUTs](https://helpguide.sony.net/ilc/2320/v1/en/contents/211h_manage_lut.html)

## 已走到哪里

| 环节 | 结论 |
| --- | --- |
| 照片 PP 到原生 LUT 加载 | **实机通过。** 保持照片挡和原菜单 PP1，只在 AP 的两个调用点适配局部参数，实机读到了视频 PPLUT1 已绑定的两份 LUT。ABA 实验确认切换绑定时加载器取到对应的文件和描述符。 |
| LUT 真正作用的位置 | **CP User3D／MLUT 与照片主图支路已定位。** AP 负责选 LUT 和提交描述符。CP 接收描述符、处理 User3D，并决定是否把效果写到主图。随后编码器消费主图缓冲。原生实机日志验证了照片与视频路径各有不同的活动，原指令离线回放走通了主图分支与编码器交接。 |
| CP 能否运行自定义代码 | **最小候选实机通过。** 使用同一条直连查询，原 CP 返回 `0x80`，冷启动后的 236 字节候选返回 `0x5A`，写回原代码再冷启动后返回 `0x80`。 |
| 同一张照片上的 User3D 回执 | **在此中断。** 下一轮为关联 AP 描述符、CP 回执和照片任务，安装了覆盖九个 CP 扇区、净改动 711 字节的记录器。写入与回读通过，随后机身冷启动黑屏，无法进入 MSC。该轮 AP 临时加载器未安装，照片没有采集，当时未能写回九个原 CP 扇区。2026-11-19 机主反馈相机已维修恢复，具体维修过程未取得。 |
| 用户功能 | 照片主图 LUT 烧录、照片取景和照片挡 PPLUT 菜单三项均待实机验收。历史 A/B/A JPEG 没有出现预设的红蓝互换。FL23／中文兼容单独跟踪。 |
