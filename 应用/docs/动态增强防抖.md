## 六个修改点

以下为解包文件偏移，不能直接作为裸闪存地址使用。物理映射、完整扇区守卫和允许写入的字节掩码由统一 profile 与配套原生载荷控制。

| 视图 | 文件偏移 | 未解锁 → 解锁 | 用途 |
|---|---|---|---|
| App | `0x4b7b93a` | `00 → 01` | 动态增强叶子列 3 菜单门控 |
| WBI | `0x2495b3a` | `00 → 01` | 常驻菜单对应门控 |
| App | `0x3ed654c` | `00 → 01` | 初始化时支持 ACTIVE_PLUS 值 |
| WBI | `0x3e2839c` | `00 → 01` | 已初始化的值支持标记 |
| WBI | `0x743f53c` | `01 → 00` | 移除恰好一项“不支持”禁用计数 |
| WBI | `0x10c4701` | `01 → 00` | 对应的抑制输出 |

计数低字节仅接受 `00`、`01`，高三字节维持零值守卫；大于 1 的计数或高字节变化会阻止操作，不强行清零。没有纳入旧的列 6/7/8 扩展候选，也没有删除高帧率、S&Q、镜头防抖开关或录像状态等原有限制。未移植或修改 CP 算法。

关闭会把以上六个字节设回未解锁值，不改当前录像防抖设置。**关闭前先在相机中切回“增强”或“标准”**，退出录像并按应用向导连接。关闭不是恢复官方固件。
