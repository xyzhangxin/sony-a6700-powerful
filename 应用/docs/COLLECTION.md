## 解锁、关闭与 USB 写入的关系

功能修改清单和离线规划器解释“要修改什么”；归集的 USB 代码解释“原来如何完成认证、发载荷、读结果和退出”；固定单扇区载荷保留原来执行明文写入及撤回的 C 实现。三个部分均可审阅，但本轮没有新增将整套离线计划变成可执行 USB 安装包的连接层。

已验证的单扇区 USB 载荷来自历史回放刷新试验，筛选功能本身无效并已撤回。归集的是写入与恢复机制，不把该历史功能放回一期功能清单。
