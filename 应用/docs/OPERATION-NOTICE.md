# 操作前须知

桌面应用首屏使用此名称，不把“打开应用”或单独的“环境检查”作为用户操作阶段。主流程为：**操作前须知 → 相机准备 → 功能主页 → 操作结果**。

## 首屏内容

- **适用范围**：现有适配与实机测试仅覆盖 Sony α6700（ILCE-6700）、固件 2.00；其他组合未验证，同版本机身仍要通过实际内容预检。
- **验证进度**：0.2 启动仅检查本机环境，完成准备后才连接相机；可切换演示。已有实机连接、功能写入与独立回读记录，仍在扩大样本。不能将“测试过该型号”写成“所有操作已验证安全”。
- **设备与数据风险**：真实修改可能造成无法启动（变砖）、设置或数据丢失。掉电、断线、机身差异和程序错误均可能导致失败；恢复不保证成功。桌面暂不提供备份与恢复入口，也不提供整盘或固件镜像恢复；“关闭解锁”不是恢复整机官方固件。
- **保修与支持**：非官方修改可能影响保修与官方售后支持；具体以当地适用政策、法律及售后判定为准，不承诺恢复后一定仍可保修。
- **免责声明**：非 Sony 官方开源项目，按现状提供；无担保及责任限制沿用 GPL-3.0-only，并以适用法律允许范围为限。首屏提供既有许可正文入口，不修改项目许可证。

运行时文案集中在 `src/a6700_unlock/notice.py`，SwiftUI 的 `OperationNotice.swift` 只负责呈现，避免把风险说明和验证状态复制成多套硬编码文字。

## 启动检查与阅读确认

启动自检自动运行。正常时显示简洁的通过状态，技术详情默认折叠；失败时显示失败项、处理办法和重新检查入口。检查只涉及本机程序与资源，不枚举相机，不表示兼容性通过。

固定底栏提供“我已阅读，并了解适用范围与真实设备操作风险”。这是当前会话内的阅读确认，不是合同签署、放弃权利、接受新许可条款或授权真实设备写入。按钮只进入相机准备。

桌面服务端同样检查 `notice_acknowledged`，不能绕过界面直接发送 `prepare` 或设备操作命令。新进程或切换模拟场景会清除确认；同一会话返回须知或重新检查环境时保留阅读状态，但相机准备和兼容状态重新确认。断连／重连不能绕过未阅读或启动失败的状态。此确认目前只用于桌面流程，物理 CLI 维持原有准备与事务规则。
