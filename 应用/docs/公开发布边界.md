## 当前 USB 功能的事实

主界面与正式 CLI 只管理 A6700 2.00 的固定功能字段；设备锁、新鲜预检、固定目标／掩码、前值和结构守卫、写后独立回读继续执行。没有交互式 root 终端或远程控制界面，不安装永久 root 开机入口。

底层仍依赖 Senser 认证和相机服务进程中的临时代码执行，源包完整披露这一事实。当前 dev25 中的底层模块与历史工具仍有通用载荷调用代码；本次仅清除原厂历史片段，不能据此宣称通用执行能力已从该二进制移除。若后续改变运行接口，须另编版本、保留完整对应源码并重新验证，不能只在源包删除仍存在于二进制的代码。
