# FTP 一次性迁移修复

Powerful6700 FTP 一次性迁移修复 1（Windows x64）
适用：ILCE-6700 固件 2.00，使用过 SonyCameraTool 1.0.0 FTP，或 0.4.2.dev1 FTP 兼容测试包。

目标：撤回阻止通用版校验的六处已知第三方修改（实际差异最多 7 字节），补齐两个 FTP 自定义键选项的 134 字节矩阵，并保留其他已解锁功能。FTP 基础字段缺失时按通用 0.4.2 的 241 字节定义补齐。

操作：
1. 退出 Powerful6700 和其他相机工具，等待所有传输结束，在相机内关闭 FTP 功能。使用此前能解锁的同一台 Windows 电脑和驱动。
2. 将整个 ZIP 完整解压到新文件夹，勿混入旧版目录。相机 USB 模式为海量存储器（MSC），仅连接这一台相机。
3. 双击“启动FTP迁移修复.cmd”。第一次只读取和检查，显示预计修改量；若检查失败，请停止并保留记录。
4. 确认执行时输入 FIX 并回车。工具会重新取得共享设备锁、重新读取，再按当前相机状态执行。不要断电、拔线或关闭窗口。
5. 只有看到“修复及独立回读通过，通用 0.4.2 原始校验通过”才算字节迁移完成。
6. 正常关机，拔掉 USB 和外接电源，取下电池至少 10 秒后重装开机。完全退出修复工具，使用原来的通用 0.4.2 点“连接并检查相机”，应能进入功能管理页。
7. 在相机的回放自定义键设置中检查“FTP传输”和“FTP传输(这个影像)”两个选项，分别绑定/验证；实际上传另行确认。

记录默认位于 %LOCALAPPDATA%\a6700-unlock\runs。反馈时提供本次目录内的 result.json、migration-result.json、public-042-inspection.json，以及两个菜单选项的照片。请保留整个记录目录，不要修改其中前态/目标文件。

边界：本包不是此前的兼容放行版；未知守卫、未知字段或未闭合写入会停止操作。使用已有事务和独立回读，不做整机恢复。迁移保留普通已解锁功能。App/WBI 自定义键矩阵在通用 0.4.2 的检查窗口之外，通用版不会管理这项矩阵的开启/关闭。通用版关闭 FTP 仍按它自己的功能定义执行。

已完成离线测试与原生 ARM64 仿真；反馈机身的菜单、重启保持和通用版实际连接仍需验收。修复后请回信分别确认：通用版连接、两个选项、实际传输。
