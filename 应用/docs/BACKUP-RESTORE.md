# 功能状态备份与恢复

当前 dev23 提供**稀疏功能状态备份**，不是整盘、分区或固件镜像。它保存工具本来就会读取的 260 个固定扇区（133,120 字节）：149 个功能字段所在扇区与 111 个结构守卫。恢复只写回当前所选功能的清单字段，结构守卫或非管理字节不一致时停止。

## 为什么不是整盘备份

设备框架的原生读写载荷只暴露清单中的固定扇区，没有任意地址或整盘读写 API。整盘镜像需要新的相机内读取器、数百 MB 级传输、独立的完整性与恢复验证，且写回整盘的风险远高于功能字段；本期不扩大可写范围，也不把窗口前镜像或稀疏备份称为整机备份。

因此：

- 可用于在解锁／关闭前保存一份当前功能状态，之后恢复工具管理的功能字段。
- 不能用于救砖、降级、恢复官方固件、恢复照片／设置或修复未由本工具管理的分区。
- 不混用明文 `/dev/nflasha*` 视图与 Pico 密文镜像。

## 备份文件

默认目录：macOS／Linux 均为 `~/Documents/A6700 Backups/`，可用 `--backup-dir` 或桌面真实模式参数指定。文件扩展名 `.a6700backup`，是带固定清单的 ZIP 容器：

| 文件 | 内容 |
|---|---|
| `manifest.json` | 格式版本、创建时间、工具版本、机型／固件、适配与清单哈希、逐扇区设备偏移／角色／哈希、功能状态 |
| `sectors.bin` | 按清单顺序排列的 512 字节扇区原始数据 |
| `README.txt` | 面向使用者的范围与边界说明 |

清单包含 `payload_sha256` 与逐扇区 `sha256`；容器只允许这三个文件，读取前检查大小、格式、版本、适配标识、扇区映射和全部哈希。文件不含相机序列号、ProductInfo 原文、密钥或主机路径。

文件名形如 `A6700-state-20261019T153000Z-1a2b3c4d.a6700backup`，不会被同名覆盖。

## 命令行

```sh
# 只读检查 + 创建备份（走完准备向导和稀疏预检）
a6700-unlock device backup

# 指定目录
a6700-unlock device backup --backup-dir ~/Desktop/a6700-backups

# 列出本机备份，不访问相机
a6700-unlock backups
a6700-unlock backups --json

# 恢复最新一份（默认）或指定文件；--dry-run 只预检
a6700-unlock device restore --dry-run
a6700-unlock device restore
a6700-unlock device restore --backup ~/Documents/A6700\ Backups/A6700-state-...a6700backup
```

`device backup` 和 `device restore` 与解锁／关闭共用本机设备锁、准备向导和每次操作的只读预检。非交互调用仍需逐项 `--confirm`，没有跳过校验的参数。

备份预检通过后写入文件；写入文件不属于相机写操作。恢复在读取当前扇区后先做主机侧计划，只有全部守卫与清单字段检查通过才发送一次写入器。

## 恢复事务

1. 读取本地备份并校验容器、清单、适配版本、全部哈希与功能字段。
2. 连接相机并读取当前 260 个扇区。
3. 比较每个守卫扇区；任何差异都阻止恢复。
4. 比较功能扇区中不属于清单掩码的字节；任何差异都阻止恢复。
5. 保存写前镜像、目标、恢复来源和写入意图。
6. 发送一次写入器；相机内再次核对全部写前内容和固定掩码，逐扇区写入、fsync、回读，明确失败时逆序回退。
7. 主机用新 nonce 独立回读；只有与备份逐字节一致且功能字段兼容时才报告 `restored`。

`restored` 仍要求关机重开验收实际功能；`no-op` 表示当前内容已与备份一致；`blocked` 表示守卫／非管理字段或适配不一致；`uncertain`、`verification-failed`、`recovery-required` 时保留操作记录，先检查状态，不盲目重试。

## 桌面入口

桌面暂时隐藏备份与恢复入口，不在“更多工具”中保留入口或展示占位按钮。待完整备份恢复实现并验证后，再重新设计用户入口。当前稀疏备份恢复的核心服务、开发者命令、文件和测试保留，原有备份不删除。

写入前的数据记录、设备锁、失败回退与独立回读不受本次界面调整影响。隐藏入口不代表已实现自动备份或“撤销上次操作”。

## 测试边界

无相机测试覆盖：备份容器结构与哈希、篡改拒绝、守卫／非管理字节阻断、恢复往返、dry-run、no-op、模拟与物理服务命令、桌面 JSON 协议。测试使用合成数据与临时目录，不访问真实相机；实机备份创建和恢复写入仍需维护者明确授权后验收。
