# 相机准备图解

当前为 A6700 简体中文菜单引导。桌面版在四行准备项右侧**常驻**显示由程序绘制的“相机界面右上角关键项”小卡，始终标明 **“示意／非实机截图”**；它不读取当前相机屏幕，也不表示应用已经检测到机身设置。菜单路径、目标值与示意选项来自 `preparation.py`，CLI 使用同一份信息。

先断开 USB 完成菜单设置，最后接线。菜单文字可能随语言、地区及固件版本有所不同，按项目名称定位，不依赖固定页码。

| 步骤 | 操作路径／方式 | 应达到的状态 |
|---|---|---|
| FTP（仅已有此菜单时） | MENU → 网络 → 传输/远程 → FTP传输功能 → FTP功能 → 关 | 首次使用没有 FTP 菜单属正常情况，选择“没有 FTP 菜单，直接继续”；已有且开启时停止传输并关闭，先前运行过 FTP 则关闭后重启 |
| USB 模式 | MENU → 设置 → USB → USB连接模式 → 海量存储器(MSC) | 选 MSC；若使用“连接时选择”，接线后选“影像传输(MSC)” |
| 自动关机 | MENU → 设置 → 电源设置选项 → 自动关机开始时间 → 关 | 提前关闭省电等待，并确认电量充足或供电可靠；不是“自动关机温度” |
| 最后接线 | 普通可传数据的 USB 线：电脑 ↔ 相机；如弹出连接方式选择，选“影像传输(MSC)” | 只连接一台目标相机，保持开机；日常操作不接 Pico 或测试板 |

FTP 入口属于本项目解锁后的菜单，A6700 原厂公开菜单没有这项。该路径依据项目已有菜单与实机记录，仍以机身实际显示为准；不把其他机型的帮助页冒充本机官方说明。确认“没有 FTP 菜单”与确认“已有菜单且已关闭”满足同一项准备条件，不要求先解锁 FTP 才能首次使用。

自动关机设置完成后可在操作结束时恢复个人原有的省电偏好。Sony 指南说明，USB 供电或连接电脑时自动关机功能会停用；本向导仍要求提前设为关，以覆盖 USB 连接切换阶段。

## 后续补实拍

现有 MSC／维护通道没有屏幕抓取实现；不能把本地桌面预览或示意图称为相机实拍。普通照片传输与菜单画面采集是不同能力。

后续优先用手机拍相机屏幕，或用 HDMI 采集设备确认能输出所需菜单后采图。[HDMI信息显示](https://helpguide.sony.net/ilc/2320/v1/zh-cn/contents/0601_hdmi_info.html) 的官方说明涉及外接屏上的拍摄信息，不能据此保证所有菜单都能被当前采集设备取得。[USB流式传输](https://helpguide.sony.net/ilc/2320/v1/zh-cn/contents/211h_usb_streaming.html) 使用独立的 USB 模式，不能与本工具要求的 MSC 当作同一个流程。

需要补充的实拍：USB连接模式选中 MSC、自动关机开始时间选中关、可选的已解锁机身 FTP功能选中关，以及接线后的 MSC 提示。记录机型、固件、语言和拍摄来源；画面不包含序列号、网络名或服务器凭据。实拍与示意保留各自标签，替换呈现组件时继续使用稳定 guide ID（`usb-msc`、`power-save-off`、`ftp-off`），不改准备状态或 USB 逻辑。
