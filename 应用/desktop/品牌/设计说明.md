# Powerful6700

应用名称为 **Powerful6700**，用于窗口、应用菜单、访达与安装包；中文功能说明继续保留。内部 Python 包名、命令、Bundle Identifier、配置和备份格式不随显示名称改变。

图标把字母 P 与简化光圈合为一个图形，采用浅薄荷绿底与深青绿主体，配色沿用应用界面。设计目标是轻量、明快、简约，使用平面几何与留白，不使用金属、发光、纹理或厚重立体效果。桌面图标不放文字，以便小尺寸识别。它是独立项目标识，不含相机厂商品牌标记。

- `Powerful6700.png`：imagegen 内置工具生成的原始图，外部背景透明。
- `Powerful6700.icns`：由原始图缩放转换的 macOS 多尺寸图标。
- 重新生成 ICNS：在工程根目录执行 `python3 scripts/build_macos_icon.py`，需要 macOS 自带的 sips 和 iconutil。
- 构建应用时，两份图像一同复制到资源目录；ICNS 用于系统图标，PNG 用于窗口页头。

生成提示词见 `生成提示词.txt`。本轮仅更新名称与视觉资源，不改变功能修改点或 USB 事务。
