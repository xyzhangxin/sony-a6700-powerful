# Pico 注入源码与释义

`pico_boot/` 包含可直接编译的板端三件套，不再要求使用者先运行上游补丁生成器：

| 文件 | 职责 |
|---|---|
| `pico_boot.ino` | USB 串口命令、PIO/DMA 发送、开漏位流编码、GP28 采样和超时释放 |
| `serialboot.pio` | 48 kbit/s 的载波、前导和位流状态机；运行使用开漏分支 |
| `serialboot.pio.h` | 上述 PIO 的生成头，编译时使用 |

源码与历史运行的 Pico v2 输入逐字节相同，版本应答 `a6700_pio_od 2`。文件名保留 Arduino sketch／PIO 工具约定；中文解释在本页。原文件中“multi-port”及 GP29／GP27 是上游的命名与预留接口，不代表当前 A6700 应按上游 Multi 接口接线。

## 本项目使用的命令

电脑送入 `命令:u8 + 长度:u16le + 数据`，Pico 回复 `0x81 ACK` 或 `0x82 ERR`。

| 命令 | 意义 | 当前主机行为 |
|---|---|---|
| `0x01` | 版本检查 | 必须精确匹配 v2 |
| `0x03` | 启停载波 | 先核对低基线，再等相机冷启动 |
| `0x04` | 发送一条 BootROM 记录 | 等待本条 PIO/DMA 完成的 ACK，不自动重发 |
| `0x07` | 空闲时设置 GP28 内部上拉 | 主机只发送关闭，不在相机接线状态启用上拉 |
| `0x08` | 采样现有 GP28，2ms 内是否出现高电平 | 不改变引脚方向，用于低基线和上电检测 |

`0x02 reset`、`0x05/0x06 UART` 为原源码保留能力，本项目主机不调用，GP27/GP29 不接相机。编译必须设置 `-DOPEN_DRAIN`，不要启用 `UART_TX`。GP28 不是普通 3.3V 推挽 TX，也不是物理第28脚；实际接线只按[硬件说明](../../../硬件说明.md)。

## 与上游的差异

来源为 DavidBuchanan314/ILCE-7M4-RE 提交 `2328d18ce640e6c8cd9341efcf0043ce9042a135`。PIO 与生成头未修改。sketch 的自有适配包括版本标签、未启用开漏时拒绝编译、启动关闭内部上拉，以及 `0x07/0x08` 命令。历史 sketch SHA-256 为 `acc13bfc67e78534ffcb1ec5164a1e45b43ce572a51f71d89b9bb489cee2cfd7`。
